## About the game

*Battle Drones* is a **mobile-friendly real-time strategy (RTS)** game by simonw, inspired by *Command & Conquer*: two armies of flying and ground drones mine scrap, raise a base, and try to destroy the enemy HQ.

- **Resources**: scrap (basic) and crystal (worth more). Harvesters mine and haul to your HQ, a Depot, or an anchored Goliath. Wrecks of destroyed units stay for a minute and can be salvaged for 30% of their cost.
- **Winning**: destroy the enemy HQ and every Goliath it has. Conversely, while one of your Goliaths stands you are not beaten even with your HQ gone.
- **Openers**: every skirmish starts with a pick — ⚡ Blitz (Fab Plant + 3 Stingers), 🔧 Industry (Fab Plant, an extra harvester, +200 scrap) or ✈ Air Wing (Airpad + 3 Wasps). The enemy picks one too.
- **Commander powers**: spend the ⚡ meter on Barrage (3 shells), EMP (freezes for 4 s) or Drop Pod (3 units land anywhere you can see). From 6:00 both sides get the Sky Hammer, an orbital strike every 2.5 minutes; every strike is preceded by a warning circle.
- **Uplinks and supply**: 📡 Uplinks sit in the contested middle of each map — holding one pays 1.5 scrap/s, lights the fog and charges ⚡ (aircraft count half, harvesters not at all; both sides inside freezes it). 📦 Supply crates drop in pairs from 1:30, every 75 s; the first unit to reach one takes it.
- **Armies**: rifle, rocket and sniper squads, Wasps, Raptors, Hornets, Mortars, Mastodons, Lancers, the Condor dropship, and the **Goliath**, a walking base built from a Gantry.
- **Modes**: ⚔ Skirmish, 🛡 Last Stand (endless waves), 🎖 Ops (handcrafted campaign), 📅 Daily Op (one seeded match a day for everyone), 🧪 Mutators, plus ten career ranks (Cadet → Marshal) and 17 medals.
- **Maps**: Proving Grounds, Riverlands, Dune Sea, Frostbite, Ashlands, Compass Rose (four players), Archipelago, plus seeded random maps.
- **Watching**: 🤖 AI vs AI with a cinematic camera (key C), and 🎬 replays.
- **Presentation**: art is generated by the original pipeline (OpenAI gpt-image-2.5); sound is synthesised live at runtime.

## What the Korean edition changes

- **A 625-entry display dictionary plus 28 regex rules** covering menus, mode tabs, map names and descriptions, difficulty, opener cards, the in-game HUD (resources, uplinks, command meter, build buttons, call-downs), the 16 unit types and the buildings with their roles, battle toasts and alerts, victory/defeat/draw screens, career ranks, and the section headings of the How-to-play panel.
- **Live Korean/English switch**: the button at the bottom right flips between the translation and the original text at any time; the choice is stored in the browser (localStorage).
- **Korean typography**: system Korean fonts (Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR) come first, no web font is downloaded, and the page is `<html lang="ko">`.
- **The original is untouched**: game logic, balance and assets are unchanged; only displayed strings are replaced, and the original text is kept per node so English mode restores it exactly.
- **Fixed terminology**: [docs/glossary.md](docs/glossary.md) records the original → Korean table (scrap, crystal, HQ, Goliath, uplink, calldown …).

### Still in English

- The body paragraphs of the How-to-play panel (its headings and key terms are translated).
- Parts of the online-duel lobby, the replay viewer, and the original developer docs (`*.md`).
- Some short map-card tokens (`Temperate`, `4 Players`, `Random`) and number-plus-noun strings such as "3 Stingers".

## How the translation works

The original hard-codes its strings in TypeScript and renders the HUD as DOM. Rather than editing source strings one by one, this fork uses a **display-time translation overlay**:

- `src/i18n/overlay.ts` watches DOM text nodes, the `title`/`aria-label`/`placeholder`/`alt` attributes and `<title>`, and replaces only strings that are in the dictionary. The original text is kept per node in a `WeakMap` and restored when English is chosen.
  - A `MutationObserver` follows UI that is drawn later or redrawn, and a 400 ms sweep catches anything missed.
  - `SCRIPT`, `STYLE`, `CANVAS` and the overlay's own bar are left alone.
- `src/i18n/ko/*.json` — the dictionary in seven files: `s` maps a source string to Korean (625 entries in total), `r` holds regex rules for dynamic strings with numbers and proper nouns (28 in total).
- `index.html` gains a single script line.
- Terminology lives in [docs/glossary.md](docs/glossary.md).

## Controls

| Action | How |
| --- | --- |
| Move / zoom the camera | Drag to pan, pinch to zoom, tap the minimap to jump |
| Select units | Tap / long-press and drag (box select) / double-tap (all of that type on screen) |
| Add to or drop from a selection (mouse) | Shift + click |
| Move and attack | Tap the ground to attack-move, tap an enemy to attack |
| Squads 1–3 | Long-press a chip to save, tap to select, double-tap to fly the camera · keys 1–3 select, Ctrl (or Shift) + 1–3 save |
| Building | Open Base, tap a structure, place the ghost on the map, confirm with ✓ Place · with a mouse, click the spot |
| Condor | Select squads and tap the Condor to load, long-press the map to fly and drop (unload key U) |
| Goliath | ⚓ Anchor (dig in) · ⇡ Lift (walk again) — key G |
| Game speed | The 1× chip by the clock gives 1.5× / 2×; hold the clock for 3× |
| Cinematic camera | C (when watching AI vs AI) |
| Pause and settings | The ❚❚ button |

## Run it locally

```bash
npm install
npm run dev            # http://localhost:5173/
```

To build exactly as deployed, under the `/battledrones-ko/` sub-path:

```bash
npx vite build --base=/battledrones-ko/
npx vite preview --base=/battledrones-ko/
```

`npm test` runs vitest plus the Pages archive check. The `ko-build` GitHub Actions workflow (triggered manually) builds with the same command, publishes to GitHub Pages, and fails if the built output still contains root-absolute paths.

## Limitation: online play

The original plays online duels over its own WebSocket relay (wss://battledrones-relay.fly.dev). This Korean edition does not modify that code, but because the overlay changes the build, the deployed bundle's version hash differs from the original's, so **an actual duel cannot be established**. The 🌐 Duel a friend online and 🔊 Duel a friend (sound) entries remain in the menu but do not connect. AI battles, Last Stand, Ops, the Daily Op, spectating and replays all work.
